# MK CPM HUB — prototipo de interfaz

Abre `index.html` en un navegador moderno para probar la interfaz.

## Funciona en esta versión
- Diseño adaptable a escritorio y móvil.
- Navegación entre Inicio, Chat, Mercado, Clubes y Perfiles.
- Búsqueda del mercado y filtro por venta/intercambio.
- Crear y eliminar publicaciones de demostración.
- Registrar clubes de demostración.
- Editar perfil local.
- Enviar mensajes en el chat local de demostración.
- Los datos de demostración se guardan en el almacenamiento local del navegador.

## Importante
Esta es la primera versión funcional del FRONT-END. No tiene todavía servidor, cuentas reales, sincronización entre usuarios, chat en tiempo real, subida de imágenes ni moderación conectada. El login y registro muestran avisos porque no se debe fingir que la autenticación está implementada. La siguiente etapa es conectar un backend seguro (por ejemplo Supabase) y probar cada flujo.
